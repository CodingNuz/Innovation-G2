# ELF firmware static summary features

A non-reconstructive, feature-only derivative of Kaggle's [IoT Firmware Image Classification](https://www.kaggle.com/datasets/datamunge/iot-firmware-image-classification) dataset (`datamunge/iot-firmware-image-classification`). The upstream dataset was last updated 2021-06-15 and reports its license as **unknown**.

## Contents

`elf_firmware_static_features.csv` has 38,887 rows and 110 columns:

- Labels: 38,073 `benignware`, 711 `malware`, and 103 `hackware`.
- `binary_label`: 0 for benignware, 1 for malware, and empty for hackware.
- Eight compilation/ELF metadata fields parsed from source filenames.
- 96 numeric aggregate features: intensity moments/quantiles/entropy, histogram proportions, adjacent-position change statistics, and statistics for sixteen 64-position blocks.
- `sample_id` and `group_id`: truncated SHA-256 pseudonyms. `group_id` keeps compiler/optimization variants of one package/program together during evaluation.

The package has **no ELF executables, JPG images, original filenames, or raw 1,024-value vectors**. Aggregate block and distribution statistics cannot reproduce the source vector. `intensity_entropy_bits` is entropy of rendered intensity levels, not whole-file entropy.

## Intended analysis

The binary task compares malware with benignware. Hackware is retained for provenance but excluded (`included_in_binary_task = 0`) rather than silently relabeled. Because the data is highly imbalanced and includes many compilation variants, use group-aware evaluation and report precision, recall, and false-negative rate—not accuracy alone.

## Provenance and caveats

Two preferred GitHub sources were evaluated first. `jrmoorthy/ELFStaticAnalysisDataset` is feature-rich but malware-only; `ashalaginov/Linux-ELF-malware-static-analysis` documents extracted records but does not distribute them. This fallback enables binary detection without downloading malware executables.

The source corpus is old and narrow, upstream licensing is unspecified, and metadata can encode collection artifacts. It should be used for private educational review, not as evidence of production detector performance.
